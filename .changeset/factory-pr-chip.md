A Factory task's sidebar row now shows its pull request as one chip: the PR number carries the state — draft, open, merged or closed — and a small dot when checks are failing or still running, so a glance tells you where the change stands. Click the chip to open the pull request on GitHub. Factory tasks stand out from orchestrator runs too: a pipeline now wears its own workflow icon with its stage count, instead of the same people icon.
