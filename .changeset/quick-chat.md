Start a quick chat with Shift-Command-N, or New chat on the Sessions page, when you want to ask an agent something without setting up a task. A chat opens empty in the current project, picks the agent you used last, and starts when you send your first message, then names itself from what you asked. Chats stay off the board and out of Needs you, so a reply never looks like work waiting on you; find them on the Sessions page or in the command palette. If a chat turns into real work, choose Make it a task from its menu to move it onto the board.
