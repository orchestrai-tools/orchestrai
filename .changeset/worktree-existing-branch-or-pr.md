Pick up work that already exists. In New Task, open the worktree's From chip and choose Existing branch or Pull request to check out a local or remote branch, or an open GitHub pull request (forks included), in a fresh worktree. When you push, the commits go back to that branch and update the pull request. A branch that is already checked out somewhere else is refused with a message saying where, and deleting the task leaves the branch in place.
