Orchestrator chats can now ship work through the Factory. Ask an orchestrator to build something and open a pull request, and it starts a Factory task for that goal — or for a backlog item — that waits for your project's Factory limits, shows in the sidebar, and ends as a draft pull request for you to review; merging it marks the linked item done. The orchestrator can choose the lead agent and model and where the task runs, and without a pull request its pipelines still run as its own helpers and report back to it, as before.
