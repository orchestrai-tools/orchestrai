There is now a Memory screen in the sidebar. Browse everything your agents have saved, search it, and filter by scope, kind or tag. Open a memory to edit or delete it, see which task saved it, view its links, and add links between memories, including memories that belong to a project. Suggestions from dreaming wait on a Proposals tab, where each one says what approving will do: duplicates and stale memories are removed after you confirm, other kinds are marked done for you to handle by hand. When an agent approves a suggestion, nothing is deleted until you press Apply. Searching for text like `#82` now works instead of failing.
