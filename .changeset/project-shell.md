The app has a new look and opens on the project shell. Home shows what is waiting on you as a board, and each open project keeps the page you left it on. Click a task card to open its conversation; a permission the agent is waiting on sits right under the task's title. Changes now shows your project's own checkout when no task is open, so you can review, commit, shelve, stash, branch, and push work on your main branch without starting a task. If your workspace file has a mistake, Services and Settings now say what is wrong instead of quietly showing nothing. Sessions lists each conversation once, even when you started it here. Press Command-K for the command palette and Command-P to open a file. Commit is Command-Return in the commit message box.
