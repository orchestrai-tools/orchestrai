Settings now has Agents and Integrations, the way you know them from Warpforge. Under Agents, install, update, or reinstall each coding agent, switch it on for new tasks, and reload its model list. Under Integrations, install language servers for the code view and connect GitHub and Linear. Every agent and language server shows its version at a glance, and an amber pill marks one with a newer version out. When something can be updated, the title bar shows how many updates are waiting, and clicking it takes you straight there. Settings also opens from Home now, with Command-comma or the Settings item at the bottom of the sidebar.
