# UI parity

Checklist for the project-first shell in `desktop-next/`. Each row is a control that exists in the Warpforge desktop app. The file paths point at the rebuilt UI on the shared kit `@warpforge/ui`, laid out after the mock in `experiments/orchestrai-shell`. A row is ticked when every control it names exists in the new UI and talks to the daemon or the shell store, not mock data. A row that is missing a piece stays open with a note saying what is not there yet.
